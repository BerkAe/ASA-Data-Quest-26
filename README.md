# ASA Data Quest 2026

Repository containing the Python scripts and resources used during **ASA Data Quest 2026**.

## About

This project includes data analysis scripts developed for the ASA Data Quest 2026. The repository contains scripts for analyzing and comparing different datasets, including ARI and SS data.

## Repository Structure

| File | Description |
|---|---|
| `ARI.py` | Analysis script for ARI data |
| `data analyze 2.py` | Additional data analysis script |
| `data analyze3.py` | Data analysis and comparison script |
| `ss 1.py` | Analysis script for SS data |
| `README.md` | Project documentation |
| `LICENSE` | Project license |

## Requirements

- Python 3.x
- Required Python libraries used by the analysis scripts

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/ASA-Data-Quest-26.git
   ```

2. Navigate to the project directory:

   ```bash
   cd ASA-Data-Quest-26
   ```

3. Run the desired Python script:

   ```bash
   python ARI.py
   ```

   Replace `ARI.py` with the script you want to run.

## Usage

Run the scripts individually according to the dataset or analysis task you want to perform.

Make sure the required datasets and Python dependencies are available before running the scripts.
